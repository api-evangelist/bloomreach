- [Batch commands](https://documentation.bloomreach.com/engagement/reference/batch-commands-2.md): **/track/v2/projects/{projectToken}/batch**<br/><br/>Executes a batch of commands.<br/><br/>Use this route when you want to execute several commands from the Tracking API group at once. You can send up to 50 commands in a batch comprising of multiple *update customer properties* and *add event* for one or more customers at once. <br/><br/>Commands in the input JSON array aren't executed sequentially in the order they appear. If timing is critical for your use case, use the `timestamp` field for events and the `update_timestamp` field for customer properties to ensure proper chronological processing. <br/><br/>However, this should not be used to run high-volume imports. This is considered bad practice and will be blocked.

- [Anonymize a customer](https://documentation.bloomreach.com/engagement/reference/anonymize-a-customer-2.md): **/data/v2/projects/{projectToken}/customers/anonymize**  A method that initiates anonymization of the specific customer.  The anonymization process removes all **Private** information and all external identifiers and assigns a new cookie ID.  Apart from customer IDs, the anonymize call only removes properties that have been marked as Private - Personal Identifiable Information (PII). You need to manually specify which properties are Private in the Data manager within your Bloomreach Engagement project. Learn more about [managing PII](doc:data-management#section-managing-pii-in-exponea).
- [Anonymize customers in-bulk](https://documentation.bloomreach.com/engagement/reference/anonymize-customers-in-bulk-2.md): **/data/v2/projects/{projectToken}/customers/anonymize_bulk** <br><br>This method initiates anonymization of multiple customers. The anonymization process removes all **Private** information and all external identifiers and assigns a new cookie ID. Apart from customer IDs, the anonymize call only removes properties that have been marked as Private - "Personal Identifiable Information" (PII). <br><br>You need to manually specify which properties are Private in the Data manager within your Bloomreach project. Learn more about [managing PII](doc:data-management).
